3. Create two classes. Student and Main.

4. Within the Student class do the following:

    - Initialize the appropriate class attributes
    - Create a class constructor with the parameters: name, height, statement1, statement2, statement3
    - Create mutators and accessors for each attribute 
    - Create a method that returns two statements as true
    - Create a method that returns one statement that you believe is a lie about another student.
    - Create a method that returns the student's height in inches.
    - Create a toString method that displays the student's info in the following format:
        
        Student: full name
        
        Height(Feet and Inches): __' __""
        
        Two Truths: 1) _____________  2) _______________
        
        Lie: ___________________

 

4. In the Main class do the following:

    - Instantiate an object of the Student class for five students in our class. 
    - Call on toString method for each student.
    - Calculate and print the sum of the class's heights in feet and inches.
